# 图片视觉导演第一版

状态：实现说明；基于本次已确认的图片策划范围。

## 目标与边界

扩展现有 `srt-visual-director`，将文案和 SRT 转成独立图片视觉方案、素材引用/缺图提示词及时间轴。保留 general 模式，不新增重复导演 Skill，不包含 TTS、生图调用、公共素材库实现或视频渲染。

公共素材库独立于项目。`media-assets` 返回候选和确认状态，导演判断视觉表达是否适合并记录引用。项目持有裁切、叠字、运动和使用时间；公共图像及其版本不会被导演修改。当前改动只定义交接，不声称已建成跨项目搜索服务。

## 单一分镜与兼容性

继续使用 `STORYBOARD.md`。新增 image-v1 图片策划 profile，把机器可读数据放在该文件唯一的 JSON 区块中；可读表是同源摘要。旧通用 schema 和已有项目保持有效。

图片策划时不强制 renderer；执行前须补齐真实素材、音频/字幕约定与 renderer 指派。契约描述向原执行字段的映射，不把规划 ready 当作渲染 ready。无 SRT 时输出无时间的 planned 草案，不生成精确时间或伪造字幕。

## 内容与质量

- 每镜一个表达目标，按语义而非固定间隔切图。
- 图内文字、后期文字、内部策划说明分层。
- 提示词完整自包含，每条对应独立图片；风格由项目决定。
- 素材走 reuse/edit/generate/search_pending/external_design 五条路径。
- 精确图表使用确定性绘图需求，不让生图模型编数据。
- SRT 解析与结构/时序约束由 Python 标准库脚本检查；事实、审美和听觉同步由实际内容审阅验证。

## 验证范围

使用合成的办公整理文案进行 SRT/交接边界测试和一次独立执行检查。没有生成图片、渲染视频或使用付费 API；不宣称完成视觉质量实测。未来用用户实际文案、参考图和真实素材库迭代。
